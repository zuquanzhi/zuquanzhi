## Zuquanzhi

Backend developer. Computer Science undergraduate at Harbin Institute of Technology (Weihai).

**Incoming @ Tencent WXG (WeChat Group)** · Previously Backend R&D Intern @ Baidu.

RoboMaster National First Prize (Vision Group) · National Intelligent Car Racing Competition, National Second Prize.

I build backend systems and developer tools in Go, and real-time vision pipelines for robots in C++/Python. I care about systems that hold up in production, and about the distance between an algorithm on paper and a machine that moves.

I write at [blog.zuquanzhi.top](https://blog.zuquanzhi.top) — technical iterations, fragments of life, and aimless thinking.

### Selected Work

- **[Gomentum](https://github.com/zuquanzhi/Gomentum)** — LLM planning agent CLI that decomposes high-level goals into executable plans. Built on Google adk-go and MCP.
- **[QuadYOLO](https://github.com/zuquanzhi/QuadYOLO)** — Real-time multi-object detection optimized for robotics. YOLOv8 + TensorRT.
- **[nano_RMVision](https://github.com/zuquanzhi/nano_RMVision)** — RoboMaster auto-aim system on embedded platforms, with Kalman-filter-based prediction.
